Constraints (sidebar, under classes): a broken rule shows as a pill next to the card's file name. Classes: comma-separated, empty or * = any.
count: number of A boxes within min..max
count_in: number of A boxes is one of the listed numbers (e.g. hole cards 0,2,4,5,6)
count_each: every class of A on its own within min..max (e.g. at most one bet / stack / nickname)
inside: every A lies inside some B (%: share of A covered by B; empty/0 = A's centre in B)
contains: every A contains min..max B (by B's centre)
overlap: no A and B overlap more than % of the smaller box (B = "=": only boxes of the same class)
size: no A differs in area from the median A by more than %
implies: if any A is present, the number of B is within min..max (empty min = 1; max 0 = A excludes B)
×N on a pill = number of offending boxes; the number on a rule = cards breaking it among loaded ones.
